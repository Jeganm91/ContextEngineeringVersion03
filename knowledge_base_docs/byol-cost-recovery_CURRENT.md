# Personally-Owned Application Subscriptions — Cost Recovery

Where an employee already holds an individually-procured subscription to an
application that is later adopted for work use, the associated recurring
charge may be submitted for reimbursement through Expense Management,
provided the tool is added to the approved software catalog first.

This is distinct from the standard licensing route described elsewhere and
does not require Procurement Lead sign-off, since no new corporate license
is being purchased.
